🌐 Network Builder Lab

Build a small office network. Tap one device, then another to add or remove a cable between them. Drag a device to move it. Then give every host a valid IP and run a ping test to prove it all works.

Status —
Goal: The two PCs and the server must all reach the network through the switch. The switch connects to the router, and the router reaches the Internet. A computer should never plug straight into the router or the Internet. Give each host an address on 192.168.1.0/24 (e.g. 192.168.1.10) — every device unique, and never 192.168.1.1 (that's the router/gateway).
