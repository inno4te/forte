Understanding CIDR

/24 = 255.255.255.0 = 254 hosts

/25 = 255.255.255.128 = 126 hosts (split /24 in half)

/26 = 255.255.255.192 = 62 hosts

/27 = 255.255.255.224 = 30 hosts

/28 = 255.255.255.240 = 14 hosts

/30 = 255.255.255.252 = 2 hosts (point-to-point links)

How VLSM works

Variable Length Subnet Masking lets you assign different-sized subnets from one address block, avoiding waste. Sort requirements largest-to-smallest, then assign the minimum subnet that fits each.

Example: 100 hosts needs /25 (126 usable). 10 hosts needs /28 (14 usable). Assigning a /25 to a 10-host requirement wastes 116 addresses.

Subnetting cheat method

Step 1 — Block size: 256 − last non-255 octet of mask = block size

Step 2 — Network: Round down the host octet to nearest multiple of block size

Step 3 — Broadcast: Network + block size − 1

Step 4 — Hosts: First = Network+1, Last = Broadcast−1

Example: 172.16.45.10 /26

Mask = 255.255.255.192 → block = 256−192 = 64

45.10 → host octet = 10 → 10÷64 = 0 remainder → Net = .0

Network: 172.16.45.0/26

Broadcast: 172.16.45.63

Hosts: 172.16.45.1 – 172.16.45.62 (62 hosts)
