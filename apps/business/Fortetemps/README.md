# ForteTemps Atelier

A working brief library for AI-assisted design, built for **inno4te · Team21 Academy**.

**Live:** https://inno4te.github.io/fortetemps/

## What this is

744 copy-ready design briefs. Each one pairs a subject domain with an aesthetic direction and produces a prompt with the palette, typography, lighting, composition and avoid-list already decided — so what comes back from an AI tool looks like a design decision rather than a default.

## Three prompt modes

Every brief can be copied three ways:

1. **Full brief** — the complete specification for building.
2. **One-liner** — condensed for quick generation.
3. **Before / after** — the amateur prompt beside the elite one, with a list of exactly what changed. This is the classroom exercise, pre-built for all 744 entries.

## Running it

A single self-contained file. No build step, no dependencies. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

The only external request is the Google Fonts stylesheet; everything else is inline.

## Source material

Built on two Team21 Academy manuals by Innocent Forteh:

- *The Professional AI Design Playbook* (Level 2) — the 12 principles of design, the creative director questions, the master prompt formula, the 100-word vocabulary, and the 9 mistakes.
- *Team21 UX Design Teaching Guide* — the five laws of good UX, the six-step design process, and the accessibility baseline: a low-end Android phone, slow data, bright sunlight, French or English.
